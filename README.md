# T5L_UI_SENSOR
迪文系列产品代码（含屏幕+传感器）

目前内容：
v1.0 包含全部逻辑
v2.0 电平输出，0-10v，每2v一档对应1-5档。
485单独输出，无法直接集成，需启用OS。
v3.0 更新电平输出协议 

> 开关阀控制
> 每个档位在执行一次后自动停止，等到档位更改再执行输出。
> 风阀执行完一个停动作后，风阀需要关闭（回到风阀0°）
> 
> 手动档位-按照档位设置
> 满档：启动供电，持续20s，停止供电
> 高档：启动供电，持续16s，停止供电
> 中档：启动供电，持续11s，停止供电
> 低档：启动供电，持续6s，停止供电
> 关闭：电源关闭时
> 控制器上电开启：默认为风阀满档位置
> 制冷模式下，
> 房间温度 < 设定温度超过3°，低档
> 房间温度 > 设定温超过1°，中档
> 否则，满档  温度回差设定2°
> 制热模式下，
> 房间温度 >设定温度超过3°，低档
> 房间温度 > 设定温超过1°，中档
> 否则，满档  温度回差设定2°
> 
> 自动档位-按照设定温度，执行档位控制
> 上电开机，满档
> 设定温度 + 1°，中档
> 设定温度 + 3°，抵档
> 温度回差2°
